🚀 快速開始（3 步驟）：
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  【第一步】複製擴充功能檔案到你的電腦
  ───────────────────────────────────────
  
  建立一個資料夾，例如 ~/Downloads/sniper-extension/
  
  把以下 5 個檔案複製進去：
    1. extension/manifest.json
    2. extension/background.js
    3. extension/content.js
    4. extension/popup.html
    5. extension/icon.png
  
  資料夾結構應該像這樣：
    sniper-extension/
    ├── manifest.json
    ├── background.js
    ├── content.js
    ├── popup.html
    └── icon.png


  【第二步】在 Chrome 中安裝擴充功能
  ──────────────────────────────────
  
  1. 打開 Chrome，輸入網址：chrome://extensions
  
  2. 右上角「開發人員模式」打開（開關）
  
  3. 左上角出現「載入未封裝項目」按鈕，點擊
  
  4. 選擇上面建立的 sniper-extension/ 資料夾
  
  5. 安裝成功！頁面會顯示「搶票助手」
  
  6. 複製下方顯示的 ID（32 碼英文字母）


  【第三步】設定網頁
  ──────────────────
  
  1. 打開 github-pages/index.html（用文字編輯器）
  
  2. 找到這一行（約第 158 行）：
     const EXT_ID = undefined;
  
  3. 改成你複製的 ID：
     const EXT_ID = "你複製的32碼ID";
  
  4. 儲存檔案（Ctrl+S）
  
  5. 重新整理網頁，應該看到：
     ✅ 搶票助手已連線 (v1.1)
