安裝搶票助手

GitHub Pages 只負責提供控制頁。要讓網頁能在指定時間開啟 Google Forms 並填入資料，Chrome 仍需要安裝這個擴充套件。

請只在你有權操作、且符合活動或平台規則的表單上使用。這個工具不會處理驗證碼、登入限制、付款流程或繞過平台保護。

1. 下載或取得擴充套件檔案

擴充套件資料夾至少需要包含：

manifest.json
background.js

2. 在 Chrome 載入擴充套件

  1. 開啟 chrome://extensions。
  2. 右上角打開「開發人員模式」。
  3. 按「載入未封裝項目」。
  4. 選擇包含 manifest.json 和 background.js 的資料夾。

3. 複製擴充 ID

載入成功後，Chrome 會顯示一組 32 碼 ID，例如：

abcdefghijklmnopabcdefghijklmnop

4. 回到控制頁

回到 搶票控制頁，把擴充 ID 貼進頁面上方的輸入框並儲存。也可以把 ID 放在網址參數：

https://你的帳號.github.io/你的repo/?ext=abcdefghijklmnopabcdefghijklmnop

5. 開始使用

  1. 輸入 Google Forms 網址。
  2. 設定啟動時間。
  3. 填好姓名、電話、Email 等資料。
  4. 按開始，保持 Chrome 開啟。
